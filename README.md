# Ре:Акция

Сайт и Telegram-бот для обращений жителей по коммунальным услугам. Оба клиента используют один backend, одну базу данных и GigaChat.

## Папки и основные файлы

- `frontend/` — готовый React-интерфейс из GitHub; `src/pages/Chat.tsx` отправляет сообщения в API.
- `backend/` — API, SQLite, миграции и связь с GigaChat; описание находится в `BACKEND_GUIDE.md`.
- `bot/` — Telegram-бот и его отдельные Docker/Python-зависимости.
- `dependencies/` — копии манифестов с точными версиями; описание находится в `DEPENDENCIES.md`.
- `docker-compose.yml` — запускает весь проект.

## База данных

Хранит пользователей, адреса, диалоги, сообщения, статьи базы знаний, заявки, историю статусов, вложения, оценки, квитанции, объявления и показания счётчиков. Файл `support.db` создаётся автоматически и хранится в Docker volume. Статьи ищутся через SQLite FTS5, поэтому тяжёлые embedding-модели и FAISS не занимают память сервера.

## Регистрация через Telegram

Пользователь отправляет боту `/register`, затем телефон, город, улицу, дом и квартиру. Бот сохраняет профиль и выдаёт шестизначный код на 15 минут. Код вводится на сайте в карточке профиля; после этого сайт и бот используют одного пользователя и общую историю обращений. Команда `/link` выдаёт новый код.

## Запуск на сервере 2 CPU / 4 ГБ

1. Установите Docker и Docker Compose.
2. Скопируйте `.env.example` в `.env` и укажите `BOT_TOKEN` и `GIGACHAT_CREDENTIALS`.
3. Выполните `docker compose up -d --build`.

Локальная модель не нужна: генерация идёт через API GigaChat, ничего скачивать не требуется. Сайт откроется на `http://IP_СЕРВЕРА`, документация API — на `http://IP_СЕРВЕРА/api/docs`.

Для проверки базы выполните из папки `backend`: `python -m unittest discover -s tests -v`.

## Ограничения MVP

- Стартовые регламенты помечены как демонстрационные; перед защитой их нужно сверить с реальными поставщиками.
- Ответ GigaChat обычно приходит за пару секунд; тяжёлых локальных моделей в compose больше нет.
- Токены и секреты хранятся только в `.env`, этот файл исключён из Git.
